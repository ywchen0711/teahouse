# 巷口茶館 · Alley Teahouse

開一間老派茶館（像春水堂那樣）。中文 / English。

- **親手做飲料**：每道飲品都有食譜：選茶、泡茶到剛好、加料、倒到刻度線、搖勻（或千萬別搖）。至少要 60 分及格才能上架販賣。
- **開店營業**：客人進門、入座、點餐，店員幫你做。遇到特別訂製（少冰、半糖……），點客人就能自己做，拿更多小費。
- **擴店佈置**：用賺到的錢擴大店面、加桌子、換牆面地板、擺燈籠、書法、金魚缸，氣氛越好客人越多。
- **茶街連線**：線上看到其他玩家的茶館，可以去拜訪、按讚（對方會收到小費），還有排行榜。
