# 巷口茶館 · Alley Teahouse

開一間老派茶館（像春水堂那樣）。中文 / English。

- **親手做飲料，照真的做法**：像真的手搖飲店一樣：拿對茶葉、煮水到對的溫度（綠茶 80°C、紅茶 95°C、鐵觀音 100°C）、按住計時泡對分鐘數、濾掉茶葉、果糖一壓一壓加、照 ml 倒到線、冰塊一杓一杓、搖勻（黑糖珍珠鮮奶、芋頭鮮奶千萬不能搖）。麻醬麵要水滾才下麵、煮 3 分鐘瀝乾再拌；滷味要回滷、切塊、淋滷汁。做錯了會用廚師的話告訴你錯在哪（「水溫 100°C 太燙：茶會苦澀」）。60 分及格才能上架。
- **一條真的小街**：路人在紅磚人行道上走過，機車從巷子騎過；有人從門口走進來、在櫃台排隊點餐付錢，再沿著桌子之間的走道走到位子坐下（也有外帶在櫃台等的）。店員收銀、做飲料、端到桌上、收桌子；朋友聊天、乾杯、先拍照；離開時揮手、店員說謝謝光臨。點客人會跟你打招呼，有特別點單（半糖少冰…）的可以自己做，拿更多小費。還可以養一隻店貓。
- **擴店佈置**：用賺到的錢擴大店面、加桌子、換牆面地板、擺燈籠、書法、金魚缸，氣氛越好客人越多。
- **茶街連線**：線上看到其他玩家的茶館，可以去拜訪、按讚（對方會收到小費），還有排行榜。
