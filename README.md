# 巷口茶館 · Alley Teahouse

開一間老派茶館（像春水堂那樣）。中文 / English。

- **親手做飲料，照真的做法**：像真的手搖飲店一樣：拿對茶葉、煮水到對的溫度（綠茶 80°C、紅茶 95°C、鐵觀音 100°C）、按住計時泡對分鐘數、濾掉茶葉、果糖一壓一壓加、照 ml 倒到線、冰塊一杓一杓、搖勻（黑糖珍珠鮮奶、芋頭鮮奶千萬不能搖）。麻醬麵要水滾才下麵、煮 3 分鐘瀝乾再拌；滷味要回滷、切塊、淋滷汁。做錯了會用廚師的話告訴你錯在哪（「水溫 100°C 太燙：茶會苦澀」）。60 分及格才能上架。
- **一條真的小街**：路人在紅磚人行道上走過，機車從巷子騎過；有人從門口走進來、在櫃台排隊點餐付錢，再沿著桌子之間的走道走到位子坐下（也有外帶在櫃台等的）。店員收銀、做飲料、端到桌上、收桌子；朋友聊天、乾杯、先拍照；離開時揮手、店員說謝謝光臨。點客人會跟你打招呼，有特別點單（半糖少冰…）的可以自己做，拿更多小費。還可以養一隻店貓。
- **擴店佈置**：用賺到的錢擴大店面、加桌子、換牆面地板、擺燈籠、書法、金魚缸，氣氛越好客人越多。
- **500 道飲料和餐點**：336 杯飲料（13 種茶：紅茶、茉莉綠茶、鐵觀音、四季春、東方美人、包種、金萱、普洱、蕎麥、麥茶、伯爵、紅玉、蜜香紅茶，各有自己的水溫和時間；純茶、奶茶、鮮奶茶、奶蓋、果茶、特調；珍珠、波霸、椰果、仙草、布丁、紅豆、芋圓、愛玉…）和 164 道餐點（乾麵、湯麵、飯、滷味、蛋餅、蘿蔔糕、水餃「點三次水」、鍋貼、小籠包、豆花、雪花冰…）。都是真的會有的搭配（水果茶不加奶，酸會讓奶結塊），每一道都有完整正確的作法。照口碑一道道解鎖，研發頁可以分類、搜尋、篩選。
- **茶街連線**：
  - 💬 茶街聊天室（還有貼圖）
  - 🏮 拜訪朋友的茶館：你會變成一位頭上有名字的客人從門口走進去坐下，可以 🧋 點一杯，對方的店員（或老闆親手）做好端給你，你會看到分數
  - 🎁 送禮：小紅包、大紅包、茶葉禮盒，或一座擺在對方店門口的開幕花籃（上面寫你的名字）
  - ✍️ 留言板、💛 好友（上線通知；朋友不在線上時，留言和禮物會等他上線才送到）
  - ⚔️ 料理對決：兩個人同時做同一道，分數高的贏
  - 🏆 排行榜：口碑、財富、研發數、滿分品項、總銷量
